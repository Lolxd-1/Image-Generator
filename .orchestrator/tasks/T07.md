# T07: Settings screen (keys + storage) and the download / delete controls
Wave: 7 · Deps: T06 · Risk: med · Model: sonnet

## Goal
A `/settings` screen where the operator pastes and manages 4-6 Gemini keys and watches the
1 GB storage budget; plus download-images, free-up-space and delete-catalog actions on the
shop and catalog screens; plus a lane indicator on the generate screen.

## Context
T06 added the typed hooks (`useApiKeys`, `useAddApiKey`, `useUpdateApiKey`, `useDeleteApiKey`,
`useTestApiKey`, `useStorageUsage`, `useShopStorage`, `usePurgeShopImages`, `useDeleteShop`)
and `useGenerateLoop(jobId, lanes)`. This task is UI only - no new API calls beyond those.

## Contracts
- Consumes (all from `../api/hooks`): `useApiKeys`, `useAddApiKey`, `useUpdateApiKey`,
  `useDeleteApiKey`, `useTestApiKey`, `useStorageUsage`, `usePurgeShopImages`,
  `useDeleteShop`, `shopImagesZipUrl`, `useGenerateLoop(jobId, lanes)`.
- Produces: route `/settings` -> `Settings` (inside `RequireAuth`).
- Produces: `formatBytes(n: number): string` - defined once in `StorageSection.tsx` and
  exported from there; "1.4 GB" / "812 MB" / "64 KB" / "0 B", one decimal above MB.

## Steps
1. `KeyPoolSection.tsx`:
   - A paste box (`Input`, `type="password"`, `autoComplete="off"`) plus an optional label
     field and an "Add key" button. Adding clears the field on success and shows a toast.
   - Explain in one line under the heading: more keys = more parallel lanes, capped at 6.
   - A list of keys, each row: label (inline-editable via `useUpdateApiKey`), the `key_hint`,
     an enabled/disabled `Badge`, "busy" when `busy` is true, `last_used_at` as a relative
     time, the current pace as `Math.round(delay_s)`s, and "available in Ns" when
     `next_allowed_at` is in the future.
   - Row actions: Test (`useTestApiKey`), Enable/Disable (`useUpdateApiKey`), Delete
     (`useDeleteApiKey`, behind `window.confirm`).
   - A disabled key shows its `disabled_reason` in `text-danger-400`.
   - Error handling: `ApiError.code === "conflict"` -> "That key is already in the pool.";
     `"auth_failure"` -> "Gemini rejected this key."; `"rate_limited"` -> "Gemini is
     rate-limiting validation right now - try again in a moment." Anything else shows
     `err.message`.
   - Summary line at the top: "N keys · M enabled · up to L parallel lanes" where
     `L = Math.min(Math.max(M, 1), 6)`.
   - MULTI-PASTE (the operator has 4-6 keys to add at once): if the pasted text contains
     newlines or commas, split it, trim, drop empties, and add them one after another,
     reporting "added X of Y" and listing any that failed with their reason. Sequential, not
     parallel - each add makes a live validation call to Gemini.
2. `StorageSection.tsx`:
   - `useStorageUsage()`. A bar showing `total_bytes / budget_bytes` with the percentage;
     tint it warning above 75% and danger above 90% (Tailwind classes already in the project's
     palette: `bg-warn-*` / `bg-danger-*` if present, otherwise reuse the tones the existing
     components use - check `Badge.tsx` before inventing class names).
   - A row per shop: name, total, and a breakdown (dish / menu / reference / export) with the
     dish count. Actions per row: "Download images" (an `<a href={shopImagesZipUrl(id)}>`
     styled as a Button - a plain link, because the response is a streamed attachment),
     "Free up space" (`usePurgeShopImages`, `window.confirm` warning that the generated images
     are deleted from storage and that they should download first; on success toast
     "Freed X") and "Delete catalog" (`useDeleteShop`, a `Modal` requiring the operator to
     type the shop name to enable the button; on success toast and invalidate).
   - Sort shops by `total_bytes` descending so the space hogs are first.
3. `Settings.tsx`: page shell matching `Shops.tsx` (`mx-auto max-w-5xl px-6 py-8`), an
   `h1` "Settings", a back link to `/`, then `KeyPoolSection` and `StorageSection`.
4. `router.tsx`: add `<Route path="/settings" element={<Settings />} />` inside `RequireAuth`.
5. `Shops.tsx`: add a "Settings" link/button in the header next to "New shop". On each shop
   card add a "Delete" action that opens the same type-the-name confirm modal and calls
   `useDeleteShop` (keep Archive - delete is the permanent one; label it clearly and give it
   the danger styling the project already uses).
6. `Catalog.tsx`: in the header, add "Download all images" (the zip link) and "Free up space"
   (purge, confirm-gated), with a line showing this shop's usage from `useShopStorage`.
7. `CatalogCard.tsx`: when `item.image_id` is null but the item is `generated`/`hosted`, show
   a neutral "image removed to free space" placeholder instead of a broken image. Read the
   component first - only that branch changes.
8. `Generate.tsx`: pass the lane count into the loop -
   `const keysQ = useApiKeys();` -> `const lanes = Math.min(Math.max(keysQ.data?.filter(k => k.enabled).length ?? 1, 1), 6);`
   -> `useGenerateLoop(jobId, lanes)`. Show "N lanes running on M keys" near the progress
   panel, and divide the existing ETA by the lane count (the ETA maths currently assumes one
   serial lane, which now overstates the wait by ~N x). Do not change `ProgressPanel`'s props
   if the value can be computed before it is passed.

## Test cases
No frontend test runner exists; `npx tsc --noEmit` plus `vite build` are the automated gates,
and each case is a code-path assertion to satisfy.
- TC1 (happy): pasting one key and pressing Add calls `useAddApiKey` once and clears the input.
- TC2 (happy): pasting five newline-separated keys adds them sequentially and reports how many
  succeeded.
- TC3 (error): a duplicate key surfaces "That key is already in the pool." and the list is
  unchanged.
- TC4 (edge): with zero keys the section shows an `EmptyState` telling the operator to paste
  a key, and `StorageSection` still renders.
- TC5 (happy): "Delete catalog" stays disabled until the typed name matches exactly
  (case-sensitive, trimmed).
- TC6 (edge): "Download images" is an anchor with a real `href`, not a fetch - the zip is a
  streamed attachment and must not be buffered in JS.
- TC7 (edge): a catalog item whose `image_id` is null renders the placeholder, not a broken
  `<img>`.
