  constraint `uq_api_keys_user_key` on `(user_id, key_hash)`) right after `User`.
  Added `leased_until: Mapped[datetime | None]` to `PaceState`, directly after

  - Added `next_step_ms: int = 0`, `key_hint: str | None = None`,
    `lanes: int = 1` to `StepResult`.

    `model_config = ConfigDict(from_attributes=True)`; `StorageUsageOut`,
